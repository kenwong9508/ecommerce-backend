# E-Commerce Backend 🛒

A Java Spring Boot backend service for an e-commerce platform.

## 🛠 Tech Stack
* **Framework:** Java / Spring Boot (Maven)
* **Git Hooks:** Husky (via Node.js)

## 🚀 Quick Start

Ensure you have **Java JDK 17** and **Node.js** installed, then run the following commands in your terminal:

```bash
# 1. Install Node dependencies for Husky git hooks
npm install

# 2. Run the Spring Boot application
./mvnw spring-boot:run          # For Mac / Linux
mvnw.cmd spring-boot:run        # For Windows
